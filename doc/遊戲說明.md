# 黑白棋 REVERSI

以 C 語言 + raylib 開發的黑白棋（Othello / Reversi）對弈遊戲。

## 建置

需求：MinGW-w64（gcc）與 raylib 開發庫（預設路徑 `%USERPROFILE%\MingW_Dev_Lib`）。

```
build.bat
```

產出 `blackandwhite.exe`（靜態連結 raylib，無需 DLL）。

## 功能

- **對戰模式**：人機對戰（執黑／執白可選）、雙人同機對戰
- **AI 三段難度**：簡單（貪心＋隨機）、普通（迭代加深 α-β，深度約 6）、
  困難（深度約 12，終局 13 空格內直接精算必勝解）
- **介面**：繁體中文、兩套主題（曜石／晨光）、可縮放視窗
- **對局輔助**：合法著點提示、懸停翻轉數預覽、提示按鈕、復原（U）、暫停（ESC）
- **動畫**：落子彈跳、漣漪式翻子、分數補間、轉場淡入淡出
- **音效**：啟動時程序化合成（落子、翻子、勝敗等），無需音檔
- **設定保存**：`settings.txt` 自動記錄音效、主題等偏好

## 操作

| 按鍵 | 功能 |
|------|------|
| 滑鼠左鍵 | 落子／點擊 UI |
| U | 復原一手 |
| H | 提示建議著點 |
| ESC | 暫停選單 |
| 滾輪 | 捲動對局紀錄 |

## 測試用命令列

```
blackandwhite.exe --demo            雙電腦對戰示範
blackandwhite.exe --shot out.png    擷取畫面後結束
```

## 架構

```
src/
  othello.c/h    規則引擎（bitboard，u64 黑白各一）
  ai.c/h         AI：α-β 搜尋 + 位置加權 + 機動力 + 終局精算（背景執行緒）
  audio.c/h      程序化音效合成
  widgets.c      主題、共用 UI 元件
  scene_menu.c   主選單與設定
  scene_game.c   對局場景（渲染、動畫、回合流程）
  main.c         進入點、虛擬畫布縮放、場景轉場
  ttfatlas.h     中文 TTF 字形圖集快取（stb_truetype）
```
